ChronoSolver

ChronoSolver is a Chrome Extension designed to assist with automated interaction workflows inside web-based quiz or test environments.

🚀 Features

Chrome Extension (Manifest v3)

Automated interaction logic

Content script injection

Lightweight and fast execution

Custom popup UI

Obfuscated production scripts for protection



Open Chrome and go to:

chrome://extensions/


Enable Developer Mode (top-right).

Click Load unpacked.

Select the project folder.

The extension will now be installed locally.


These are required for injecting and executing automation scripts.

📦 Version

Current Version: 5.0
Manifest Version: 4.1
